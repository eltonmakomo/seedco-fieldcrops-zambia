# Seed Co Zambia Field Crops

Redesign the Seed Co Zambia Field Crops website using https://seedcogroup.com/zm/fieldcrops/ as the primary source for ALL existing content, pages, products and navigation. Use the Seed Co Group website http://139.84.241.235/scg/ as the main brand and visual reference.

Create a modern, clean, professional and creative agricultural website that feels like a natural evolution of the Seed Co Group brand without copying its layout.

IMPORTANT:

- Preserve all existing live-site content and information architecture.

- Recreate ALL available Field Crops pages, including About, Products, Product Details, Innovations, Farmers’ Hub, Media, FAQs, Contact and other existing pages.

- Make every navigation item, button, card and CTA functional and link to the correct equivalent page in the redesigned site.

- No dead links, placeholders or missing pages.

DESIGN:

- Premium African agricultural aesthetic

- Clean layouts, generous whitespace and strong typography

- High-quality crop/farmer imagery

- Modern product cards and content sections

- Subtle animations and micro-interactions

- Fully responsive

Build the website as a reusable COUNTRY FIELD CROPS TEMPLATE so the same structure can later be adapted for other Seed Co African country websites by changing country-specific content, products and imagery.

Keep the Seed Co identity, green-led visual language and overall Group feel while making the experience significantly more modern and engaging.
